# Neon Rift

Небольшой браузерный неоновый рогалик с видом сверху. Враги — бешеные плюющиеся медведи: 8 волн, выбор улучшений между волнами и финальный босс Король-гризли с тремя фазами. Забег длится около 5 минут.

## Стек
- Чистый JavaScript и Canvas 2D: без движков, сборщиков и npm-зависимостей.
- Звук синтезируется через WebAudio, внешних файлов нет.
- Игровая логика (`js/game.js`) не зависит от DOM и тестируется в Node.

## Запуск
Вариант 1: скопировать папку к себе и открыть `index.html` в браузере (работает по `file://`).

```bash
scp -r user@server:~/projects/play_1 ./neon-rift
```

Вариант 2: раздать файлы с сервера и открыть через SSH-туннель:

```bash
# на сервере
cd ~/projects/play_1 && python3 -m http.server 8000 --bind 127.0.0.1
# на своей машине
ssh -L 8000:localhost:8000 user@server
# затем в браузере: http://localhost:8000
```

## Управление

### Телефон (APK или мобильный браузер)
| Жест | Действие |
|---|---|
| Левый палец | движение (стик появляется под пальцем, аналоговый) |
| Правый палец | прицел (огонь автоматический) |
| Кнопка «РЫВОК» | рывок, вокруг кнопки — индикатор перезарядки |
| Кнопка ‖ / «Назад» | пауза: продолжить, звук, в меню |
| Тап по карточке | выбор улучшения |

### Клавиатура и мышь
| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение |
| Мышь | прицел (огонь автоматический) |
| Пробел / Shift / ПКМ | рывок (короткая неуязвимость) |
| 1 / 2 / 3 или клик | выбор улучшения |
| Esc | пауза |
| M | звук вкл/выкл |
| Q (на паузе или в финале) | в меню |

## Структура
- `js/engine.js`: ГПСЧ с seed, пул объектов, утилиты.
- `js/game.js`: враги, волны, улучшения, босс, столкновения.
- `js/render.js`: неоновая отрисовка, частицы, HUD, экраны.
- `js/audio.js`: синтез звуковых эффектов и фоновой музыки.
- `js/touch.js`: сенсорное управление (два плавающих стика, кнопки рывка и паузы).
- `js/ios.js`: особенности iOS (безопасная зона, звук, запрет зума).
- `manifest.webmanifest`, `sw.js`, `icons/`: PWA для iPhone.
- `js/main.js`: ввод, игровой цикл с фиксированным шагом 60 Гц, рекорды в `localStorage`.
- `test/sim.js`: headless-симуляция, в которой бот проходит игру.

## Тест логики
```bash
node test/sim.js 10
```
Запускает 10 забегов бессмертного бота (проверка проходимости и длительности) и 10 забегов обычного бота (оценка сложности). Проверяет, что в состоянии игры нет NaN и исключений.

## iPhone (iOS, PWA)
**[▶ Открыть игру](https://ivanch9.github.io/play_1-ios/)** в Safari на iPhone, затем **«Поделиться» → «На экран Домой»**.
Игра появится иконкой и будет запускаться на весь экран, без панелей Safari, и работать офлайн.
Проверено под iPhone 13 Pro / iOS 16.5, подходит iOS 16.4 и новее.

- Управление то же, что на Android (см. таблицу выше). Аналога «Назад» нет — пауза кнопкой ‖.
- Кнопки и HUD не попадают под вырез («чёлку») и полоску «Домой».
- Ориентацию iOS заблокировать не даёт: в портретном режиме игра просит повернуть телефон.
- Звук включается с первого касания. Если звука нет — проверьте боковой переключатель «Без звука».
- Вибрации нет: Safari на iOS её не поддерживает.
- Рекорды у иконки на экране «Домой» и у вкладки Safari хранятся отдельно.

Технически это та же веб-версия плюс `manifest.webmanifest`, `sw.js` (офлайн-кэш), `icons/` и `js/ios.js`
(безопасная зона, разблокировка звука, запрет зума). После изменения файлов игры увеличьте `VERSION` в `sw.js`,
иначе установленные копии продолжат брать старые файлы из кэша.

Локальная проверка с телефона: service worker и установка на экран «Домой» требуют HTTPS
(подойдёт GitHub Pages: Settings → Pages → Deploy from branch `main`, папка `/`).

## Android (APK)
**[⬇ Скачать neon-rift.apk](https://github.com/Ivanch9/play_1-andoid/releases/latest/download/neon-rift.apk)** — последний релиз
(все версии: [Releases](https://github.com/Ivanch9/play_1-andoid/releases)).

Веб-версия упакована в полноэкранный WebView (`android/`): ландшафт, без системных панелей, экран не гаснет,
вибрация при уроне, кнопка «Назад» ставит паузу. Требуется Android 8.0+ (minSdk 26, targetSdk 35 — Android 15).
Готовый APK весит около 50 КБ.

Сборка идёт без Gradle и Android Studio (`aapt2 → javac → d8 → zipalign → apksigner`), нужно ~0.8 ГБ:
JDK 17 и пакеты SDK `build-tools;35.0.0`, `platforms;android-35`.

```bash
# один раз: JDK 17 (Temurin) в ~/android-tools/jdk, commandline-tools в ~/android-tools/sdk/cmdline-tools/latest, затем
~/android-tools/sdk/cmdline-tools/latest/bin/sdkmanager --sdk_root=$HOME/android-tools/sdk \
  "build-tools;35.0.0" "platforms;android-35"

./android/build.sh          # → android/build/neon-rift.apk
```

При первой сборке создаётся ключ подписи `~/android-tools/neonrift.p12` и файл с паролем `~/android-tools/neonrift.pass`
(вне репозитория). **Сохраните их**: обновление поверх установленного приложения возможно только с тем же ключом.

Установка на телефон: скачать APK по ссылке выше, открыть, разрешить «Установку из неизвестных источников» для браузера/файлового менеджера.
Play Protect может предупредить о неизвестном разработчике: «Подробнее → Всё равно установить».

### Переменные окружения сборки (все необязательные)
| Переменная | По умолчанию |
|---|---|
| `ANDROID_TOOLS` | `~/android-tools` |
| `ANDROID_SDK` | `$ANDROID_TOOLS/sdk` |
| `JAVA_HOME` | `$ANDROID_TOOLS/jdk` |
| `NEONRIFT_KEYSTORE` | `$ANDROID_TOOLS/neonrift.p12` |
| `NEONRIFT_KS_PASS` | пароль ключа; если не задан — берётся из `$ANDROID_TOOLS/neonrift.pass` |
| `VERSION_CODE`, `VERSION_NAME` | `2`, `2.0` |

У самой игры переменных окружения нет.
